## 1. 🎯 Мета та проблематика PoC

Сучасні автономні AI-асистенти та LLM-агенти (Cursor, GitHub Copilot, розширення Claude/GPT) стикаються з фундаментальним бар'єром під час тривалої інженерної розробки: **ентропійною деградацією контексту**.

### Типові системні вади «чистих» LLM у великих проєктах:
1. **Дрейф уваги та амнезія (*Attention Drift / Lost in the Middle*):**  
   Після 30–50 кроків діалогу модель втрачає початкові інструкції, плутає архітектурні ролі та спотворює предметну область.
2. **Галюцинації коду та інтерфейсів (*Hallucinations*):**  
   За відсутності зв'язку з версіонованою істиною агент починає посилатися на вигадані бібліотеки, функції та неіснуючі файли.
3. **Некерований скриптовий хаос (*Runaway ReAct Loops*):**  
   Агент безконтрольно плодить одноденні скрипти (`test_v2_fixed.py`), спамить невалідними викликами термінала та потрапляє у нескінченні цикли виправлення помилок.
4. **Апаратна сліпота (*Hardware Ignorance & OOM Crash*):**  
   Модель не усвідомлює фізичних меж хоста: спроби запустити важкі моделі на локальному CPU спричиняють вичерпання RAM, викидання процесів у SWAP та зависання операційної системи.

## 2. 🏛️ Архітектурне розв'язання: Зовнішній кіберфізичний екзоскелет

Цей модуль містить матеріали **Proof of Concept (PoC)**, який на практиці доводить:  
> **Ймовірнісні вади нейромереж неможливо виправити текстовими вмовляннями («будь уважним»). Їх можна надійно купірувати виключно за рахунок зовнішнього детерміністичного каркаса (External Deterministic Scaffolding).**

Фреймворк **Hybrid Agentic IDE** трансформує стохастичну LLM у передбачуваний обчислювальний вузол за рахунок 5 інженерних бар'єрів:

```
┌────────────────────────────────────────────────────────────────────────┐
│                   HYBRID IDE DETERMINISTIC SCAFFOLDING                 │
├────────────────────────────────┬───────────────────────────────────────┤
│ [1] Tier 3 Git-Cache Memory    │ Знання вивантажуються у файли Markdown│
│                                │ під Git. Нульовий дрейф уваги.        │
├────────────────────────────────┼───────────────────────────────────────┤
│ [2] Pre-Tool Hard Deny Gates   │ Фізичний перехоплювач префіксів у OS. │
│                                │ Блокування інлайн-евалу та деструктиву│
├────────────────────────────────┼───────────────────────────────────────┤
│ [3] Git-First Local Access     │ Читання тільки через git show HEAD:...│
│                                │ 34-пунктний валідатор за 0.001 с.     │
├────────────────────────────────┼───────────────────────────────────────┤
│ [4] Hardware-Software Co-Design│ Ценз RAM 16 ГБ, моделі <=7B локально, │
│                                │ оверфлоу на 460 tok/s Groq LPU 120B.  │
├────────────────────────────────┼───────────────────────────────────────┤
│ [5] Canonical /bridge Protocol │ Безшовна серіалізація стану та повна  │
│                                │ ліквідація міжсесійної амнезії.       │
└────────────────────────────────┴───────────────────────────────────────┘
```
